# Whoop Obstacles

Каталог препятствий для трасс whoop-дронов (65–75 мм): текстовые описания, размеры и чертежи. Основа для 3D-моделей в симуляторе.

85 элементов, 112 вариантов, у каждого варианта — SVG-чертёж. Полный список — в [INDEX.md](INDEX.md).

## Структура

```
obstacles/
  01-gates/                 категория
    G01-ring/               элемент
      element.yaml          описание элемента и его вариантов
      drawings/             чертежи вариантов (G01-a.svg, G01-b.svg…)
tools/
  index.py                  пересобирает INDEX.md и показывает прогресс
  check.py                  проверяет каталог: поля, ID, цвета, наличие чертежей
  draw_all.py               пересобирает все чертежи
  drawlib.py                общая библиотека чертежей (виды, размеры, лист SVG)
  draw_<категория>.py       чертежи одной категории (gates, tunnels, markers, barriers,
                            combos, dynamic, interior, outdoor, service)
INDEX.md                    сводная таблица (генерируется)
TEMPLATE.yaml               шаблон нового элемента
```

| Папка | Буква | Что внутри | scope |
|---|---|---|---|
| `01-gates` | G | ворота: кольца, рамки, LED, сетки ворот | track |
| `02-tunnels` | T | тоннели: тканевые, каркасные, с поворотом, развилкой, окнами | track |
| `03-markers` | M | огибаемые ориентиры: флаги, конусы, шесты, слалом | track |
| `04-barriers` | B | планки, стенки с окнами, ленты, сетка, щели, лабиринт | track |
| `05-combos` | C | составные гоночные элементы: split-S, шпилька, лестница, спираль… | track |
| `06-dynamic` | D | подвижные: вращающиеся ворота, маятник, заслонка, качающееся кольцо | track |
| `07-interior` | I | мебель и элементы квартиры | indoor |
| `08-outdoor` | O | уличные объекты | outdoor |

## Идентификаторы

- Элемент: буква категории + номер — `G01`.
- Вариант: ID элемента + буква — `G01-a`, `G01-b`.
- Чертёж варианта: `drawings/<id варианта>.svg`.
- ID не переиспользуются: удалённый элемент оставляет дыру в нумерации.

## Поля

Общие поля задаются на уровне элемента. Вариант наследует их и может переопределить любое поле, например `color` или `mount`.

| Поле | Значение |
|---|---|
| `id`, `name_ru`, `name_en` | идентификатор и названия |
| `category` | категория (совпадает с папкой) |
| `scope` | `track` — трасса, `indoor` — интерьер, `outdoor` — улица, `service` — служебное |
| `behavior` | `static` / `dynamic` |
| `status` | `draft` → `filled` → `reviewed` |
| `description` | как выглядит, из чего состоит |
| `real_analog` | реальный предмет-аналог (без брендов) |
| `mount` | `floor`, `stand`, `hanging`, `wall`, `free` |
| `material` | материал |
| `rigidity` | `soft` / `semi` / `hard`: как объект ведёт себя при ударе вупа |
| `color` | цвет(а) |
| `difficulty` | сложность прохождения, 1–5 |
| `motion` | только для `dynamic`: `type` (rotation / swing / linear / open-close), `axis`, `period_s`, `amplitude` и пояснения (окно прохода, цикл, зона потока) |
| `dimensions_mm` | габариты объекта целиком |
| `aperture_mm` | проходной проём (то, во что должен пролезть дрон) |
| `components` | у составных элементов — из каких элементов каталога собран (например, `2 × G03-c + M05`) |
| `drawing` | путь к чертежу варианта |

## Соглашения

- Все размеры в миллиметрах.
- Оси: X — ширина, Y — высота (вверх), Z — глубина (направление пролёта).
- Точка привязки объекта — центр основания (там, где он стоит на полу или крепится).
- Дрон: whoop 65–75 мм. Минимальный проходной проём — 150 мм.
- Чертёж: SVG, вид спереди и сбоку, размеры подписаны в мм.

### Размеры

- `dimensions_mm.width / height / depth` — габаритный прямоугольник объекта целиком, вместе с подставками и ножками.
- Остальные ключи в `dimensions_mm` описывают форму: `diameter`, `band` (ширина ленты/профиля рамки), `tube` (диаметр трубки), `side`, `across_flats` и т. д.
- `aperture_mm.shape` — форма проёма: `circle`, `rect`, `triangle`, `hexagon`, `octagon`, `arch`, `grid`, `keyhole`, `posts`…
- `aperture_mm.bottom` — высота нижнего края проёма над полом. По ней симулятор ставит объект на трассе.
- У огибаемых объектов (флаги, конусы, столбы, глухие стенки) проёма нет: `aperture_mm: { shape: "none" }`.
- Пролёт над препятствием — `shape: "over"` с `min_height` (высота верха, выше которой надо пройти); под ним — `shape: "under"`.
- Подпись варианта (`label`) у ворот — **внешний** размер. Размер проёма всегда лежит в `aperture_mm`.

### Цвета

Цвет пишется словом и HEX-кодом: `"оранжевый #FF6A00"`. Соседние по трассе ворота лучше делать разных цветов.

## Прогресс

```
pip install pyyaml
python tools/check.py     # проверка каталога
python tools/index.py     # пересборка INDEX.md и счётчик статусов
```

`check.py` ругается на пустые обязательные поля, неверные значения (`scope`, `mount`, `rigidity`…), цвета без HEX-кода, сбитые ID вариантов и отсутствующие чертежи. Запускай перед каждым коммитом.

Статусы: все элементы сейчас `filled`. После проверки другом (размеры подходят для симулятора) — ставить `reviewed`.

## Чертежи

```
python tools/draw_all.py            # все чертежи
python tools/draw_gates.py          # одна категория
python tools/draw_gates.py G01 G05  # только выбранные элементы
```

Чертежи строятся из `element.yaml`: поменял размер — перезапусти скрипт, и чертёж обновится. Руками SVG не править.

На листе два вида, пол заштрихован, зелёная стрелка — направление пролёта. Серые размеры — габариты, синие — проходной проём.

- Ворота: вид спереди + вид сбоку (у G10 — вид сверху).
- Тоннели: вид сбоку + вид на вход. У изогнутых и разветвлённых (T02, T08) основной вид — сверху, у T09 вместо входа — разрез по окнам.
- Маркеры: вид спереди + вид сбоку или сверху. У M06 и M07 на виде сверху пунктиром показана траектория облёта.
- Составные элементы: на одном из видов пунктиром показана траектория манёвра (split-S, разворот, змейка, спираль, петля).
- Барьеры: вид спереди + вид сбоку. У ширмы B08 второй вид — сверху (зигзаг створок), у лабиринта B09 основной вид — сверху с траекторией, второй — вид на вход.
- Динамика: крайние положения движущихся частей — бледным пунктиром, движение — оранжевой стрелкой.
- Интерьер, улица, служебные: обычные виды; у I10 (вентилятор) голубым показана зона нисходящего потока.

Обычно оба вида в одном масштабе. Если виды несоизмеримы (тонкий шест и траектория длиной несколько метров), у вспомогательного вида свой масштаб — это подписано в его заголовке.
